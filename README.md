# GAME HACK

**みんなが知っている「現実」を、スマホで遊べるミニゲームにする参加型リポジトリです。**

遊ぶ → https://k-ito-schoolagent.github.io/game-hack/

## 発想の型

このリポジトリのゲームは、すべて同じ「型」でできています。

1. **題材は、みんなが知っている現実** — 満員電車、ハンコ決裁、年賀状、桜前線、終電……
2. **抽象概念を物理化する** — 「混雑」を積み上がる箱に、「決裁」を流れる書類に
3. **技術でクリアできる** — 乱数で勝敗を決めない。パターンは固定か実データ。覚えれば上手くなる
4. **失敗を見せ場にする** — 「ドアが閉まりません」「監査が入りました」。失敗がいちばん面白い

## ゲームづくりの約束

- **乱数で勝敗を決めない** — 出現パターンは実データか固定シーケンス（覚えられる＝RTAが成立する）
- **失敗はプレイヤーに帰因する** — 理不尽な死はなし。理論上ノーミスクリア可能
- **スマホ縦持ち・親指操作** — タップ領域 44px 以上、safe-area 対応
- **単一ファイル `index.html`** — 外部依存なし・ビルド不要。`games/<id>/` に置くだけで公開される
- **データの出典を明記する** — 気象庁などの公開データを使う場合はゲーム内に書く

雛形は [_template/](_template/) にあります。
