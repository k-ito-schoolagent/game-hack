# GAME HACK

**みんなが知っている「現実」を、スマホで遊べるミニゲームにする参加型リポジトリです。**

遊ぶ → https://k-ito-schoolagent.github.io/game-hack/

## 発想の型

このリポジトリのゲームは、すべて同じ六つの「型」でできています。くわしい説明・見分け方・企画シートは **[METHOD.md](METHOD.md)** へ。

1. **題材はファンタジーではなく「全員が知っている現実」** — 台風・カレンダー・満員電車・年賀状。ルール説明がほぼ不要で、だれにでも一瞬で伝わる
2. **抽象概念の「物理化」** — 予定＝重力で崩れる箱、台風＝予報円つきの円、日本列島＝掴める物体。現実のしくみのルールを、そのままゲームの物理法則に翻訳する
3. **現実ではありえない権限を一つだけ与える** — 「日本列島を動かせる」「他人の予定を無理やりねじ込める」。この倒錯が笑いと快感の核
4. **失敗を最高の見せ場にする** — 箱の雪崩、上陸地方名のテロップ、「ドアが閉まりません」。負けた瞬間がいちばん面白いから、リプレイと共有が回る
5. **本物のデータ・UIへのこだわり** — 気象庁のデータ、実在の海岸線、稟議書の決裁欄、駅の発車標。実在感が没入と「これ見て」を生む
6. **操作は一つに絞る** — ドラッグだけ／タップだけ／スライドだけ。親指一本で遊べる

## ゲームづくりの約束

- **乱数で勝敗を決めない** — 出現パターンは実データか固定シーケンス（覚えられる＝RTAが成立する）
- **失敗はプレイヤーに帰因する** — 理不尽な死はなし。理論上ノーミスクリア可能
- **操作は一つ・スマホ縦持ち・親指操作** — タップ領域 44px 以上、safe-area 対応
- **画面の言葉は場面の中の言葉で** — 車内放送・上司のひと言・気象庁のテロップ。「失敗は学び」のような場面の外からの説明や励ましは置かない
- **見た目はゲームごとに変える** — 共通なのは操作の骨格（上の帯・一時停止・下から出る結果シート）だけ。色や書式はそのゲームの世界に合わせる
- **単一ファイル `index.html`** — 外部依存なし・ビルド不要。`games/<id>/` に置くだけで公開される
- **データの出典を明記する** — 気象庁などの公開データを使う場合はゲームの最初の画面に書く。確かめられない値は「概略値」と書く

雛形は [_template/](_template/) にあります。
