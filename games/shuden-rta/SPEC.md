# 終電乗り換えRTA（仕様書）

> ステータス: **実装済み**（`index.html`）。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 飲み会がお開きになった後の「終電までに帰れるか」の緊張 |
| 物理化（概念→物理オブジェクト） | ダイヤ＝路線図の上を時刻どおりに動く電車。乗換＝固定の歩き時間（発車標の「乗換」列） |
| 権限（現実ではありえない1つ） | 全社・全路線の電車の現在位置が、1枚の路線図でリアルタイムに見える（終電は琥珀色で塗られる） |
| 技術（習熟でクリア可能にするもの） | ダイヤは完全固定。最適な乗り継ぎを覚えれば必ず間に合う（RTA） |
| 失敗の見せ場 | 目の前でドアが閉まる → 深夜の駅前のタクシー乗り場 → 感熱紙のタクシー領収書（新運賃で計算） → 判子「終電逃」 |
| クリア | 最寄り駅の改札を出る → 丸印「帰宅」 |
| 操作（スマホ親指・1操作） | タップだけ。駅では発車標の電車を、車内では降りる駅をタップ |

## 画面

- 上半分: 路線図（山手線・中央線快速・銀座線・丸ノ内線・東横線の21駅）。全列車の位置、終電、自分の位置。駅名は路線・駅・凡例に触れない位置へ自動配置
- 下半分: 駅＝ホーム（駅名標・人物）＋LED発車標（路線/種別/時刻/行先/番線/乗換分）、通路＝乗換の歩き、車内＝ドア上の表示と停車駅一覧
- HUD は発車標風（現在時刻）。結果シートは感熱紙の書式。失敗時はタクシー領収書（乗車/降車/走行距離/合計）

## データ

- ダイヤ: 平日の実際の終電を参考にした簡略化した固定ダイヤ（Yahoo!乗換案内 transit.yahoo.co.jp、2026-10-02 確認）。ゲーム内の終電は実際と一致させている: 新橋 山手線外回り 0:50 品川行・内回り 0:34 池袋行／東京 中央線快速 0:06・新宿 0:21 武蔵小金井行／新橋 銀座線 0:15 渋谷行／東京 丸ノ内線 0:11 新宿行／渋谷 東横線 0:21 元住吉行。途中駅の時刻・番線・乗換時間・運転間隔は概略値
- ラインカラー: 山手 #9ACD32 / 中央快速 #F15A22 / 銀座 #FF9500 / 丸ノ内 #F62E36 / 東横 #DA0442。駅ナンバリングは各社公式
- タクシー: 東京都特別区・武三地区 普通車（2026-04-20 改定、taxi-tokyo.or.jp）初乗 1.0km 500円・232m ごと 100円・深夜 2 割増。距離は駅間の直線距離×1.32。深夜割増は運賃×1.2 を 100 円単位に切り上げた概算（実際は距離単位を短縮する方式）
- 東西線（大手町 0:13）・半蔵門線（渋谷 0:12）も調査したが、路線図の読みやすさを優先して 5 路線に絞った

## 公平性（node / ブラウザで全面検証）

- 乗り継ぎには人がタップする余裕 `REACT=0.6` 分（駅では約3秒）を必ず見込む。最速計算・帰れるかの判定・失敗理由はすべて同じ基準
- 乗車直後は 1.8 秒ドアが閉まるまで時間が止まり、その間に降りる駅を選べる
- 全 6 面: 反応 0.5〜4 秒のボットが最適経路でクリア。各面の最初の一手をすべて試し、帰れる／帰れないがソルバーと全件一致

## 実装の約束（GAME HACK 共通）

- 乱数で勝敗を決めない（ダイヤ固定。乱数は使っていない）
- 失敗は必ずプレイヤーの選択に帰因（どの電車に乗った時点・どの駅を通過した時点で帰れなくなったかを示す）
- 単一ファイル・外部依存なし・ビルド不要。共有ボタン（𝕏）とポータルへの導線あり
