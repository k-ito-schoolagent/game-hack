# 屋根雪おろし（仕様書）

> ステータス: **公開中（No.08）**。改良の提案は issue へ。はじめての PR 歓迎。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 雪国の冬の重労働と「落とす向き」の判断 |
| 物理化（概念→物理オブジェクト） | 屋根の雪＝斜面上のかたまり（片面3〜4個）。凍着しているかたまりは動かず、押されたかたまりはトタンの上を加速して滑る。ぶつかった雪は一緒に動く（完全非弾性衝突）。日が当たってゆるんだ面では、下の支えを失った雪が自分から滑り出す（連鎖） |
| 権限（現実ではありえない） | 屋根の雪のかたまりの重さ（kg）が見える |
| 技術（習熟でクリア可能にするもの） | 重さと置き場の残り（kg）を見て、どのかたまりを・どの向きに・どの強さで・どの順番で押すかを決める。軽い棟ぎわの雪だけが、強く押せばカーポートを越えて流雪溝まで飛ぶ |
| 失敗の見せ場 | 隣家に落とす／隣との間を埋める「ご近所トラブル」、カーポート直撃・庭の雪山があふれる「カーポート崩落」、道路の通学の子ども・隣のおばあちゃんの目の前に落とす「通学路に落雪」、上の雪や押し戻された雪に「巻き込まれ」。判子は「崩落」、クリアは丸印「完了」 |
| データ（実データ＝固定パターン） | 気象庁の最深積雪（地点別の観測値）を各面の積雪深に使用 |
| 操作（スマホ親指・1操作） | かたまりを、落としたい向き（軒へ／棟へ）にはらう。はらう長さで強さが3段階（弱・中・強） |

## 見た目（このゲームの世界の書式）

- HUD: 町内の琺瑯掲示（生成り地・紺の文字・二重罫）。中央に置き場の残り（kg）
- シート: 町内会の回覧板（緑の板・金属クリップ・罫線入りの回覧用紙・明朝の見出し・「雪国町内会 除雪当番」）。失敗は角印「崩落」、クリアは丸印「完了」
- 共通UIの JS/HTML 構造はそのまま。CSS 変数の再定義と、共通ブロックの後ろの追加 CSS で上書きしている

## 画面構成（論理座標 W=420・H=700〜920）

- 横: 隣家の軒の 0.7m 外側〜右の軒から 4.75m（道路の端）までが横幅いっぱい（約21px/m）。屋根の雪が横幅の約75%を占める
- 縦: **描画だけ縦を KY 倍に誇張**（H=700 で 1.3 倍 → H=920 で 1.6 倍。物理は等倍）。屋根の勾配は少し急に見える。はらう向きの判定と矢印も同じ倍率で計算している
- 地面: 屋根の雪の上下の中心が画面の約66%に来る位置。ただし地面より下に 100px 以上残す
- 地面より下の帯（断面）: 左に「隣との間」、右に「庭」の置き場のピット。落とした雪の量に応じて下から積み上がり、破線＝満杯。上に残りkg（1,500kg 未満で朱）。第1面は上限なしなので破線なし・落とした量を表示。右端に流雪溝のU字断面と流れる水。はじめの数秒の手引きもこの帯に出る（最初にはらうか5秒で消える）
- 雪尺（スノーポール）: 隣家との間の手前に立つ。赤白50cm刻み・1mごとの目盛り、その日の積雪深に印と値（183〜566cm）
- 背景: 遠くの山と杉林、裏の通りの雪をかぶった家並み、電柱と電線
- 重さ（kg）の表示: 屋根の雪の上にそろえた2段の帯に、各かたまりの真上に置き、細い引き出し線でつなぐ（隣どうしは段を互い違い）。measureText で実測し、ほかの表示・引き出し線・自分（人物）・雪尺・上の帯に重なれば2段ずつ上げ、それでも収まらなければ縮める（下限10px）。引き出し線は人物の後ろを通す
- 帯の文字は降る雪より手前に描く。通行人は画面の右端からはみ出さない位置に描く（当たり判定の位置は変えない）

## 物理（決定的・乱数なし）

- 屋根に沿った1次元の運動（刻み 1/240 秒）。動いている雪の加速度は斜面方向に 0.4 m/s²（動摩擦を勾配よりわずかに小さく設定）
- 押す力 J（弱・中・強）を重さ m で割った初速 v0 = J / m。重い雪ほど動かない
- 棟へ押し上げた雪が棟を越えられないと滑り戻り、押した人を巻き込む。反対側の棟ぎわに雪が残っていると越えられない
- 軒から飛び出した雪は放物線で落ちる。カーポートは屋根の高さ 2.2m で当たり判定（右の軒から 1.1〜1.9m）
- 着地点（右の軒からの距離）: 1.1m 未満と 1.9〜2.7m は庭（カーポートのない第1面は 2.7m 未満すべて）、2.7〜3.6m は流雪溝（上限なし）、3.6m より先は道路。左は 1.3m（第5面 1.5m）より先が隣家
- 通学路の通行人は16秒周期の固定ダイヤ（子ども2人・隣のおばあちゃん）。路地の雪壁の陰（2.4〜3.7m、当たらない）から出て、道路を画面の右端（4.45m）まで歩いて消える。見えている人にしか当たらない。道路に落とすときは人のいない時をねらえばよい

## ノーミスでクリアできることの検証

`index.html` の SIM ブロックと STAGES をそのまま取り出して、全手（かたまり×向き×強さ）を幅優先探索するソルバーで確認した（通行人は待てば避けられるので除外）。

| 面 | 最短ノーミス手数 | 初手で失敗しない手 |
|---|---|---|
| 1 青森 | 3手 | 11 / 36 |
| 2 十日町 | 5手 | 4 / 36 |
| 3 津南 | 5手 | 2 / 36 |
| 4 肘折 | 6手 | 1 / 48 |
| 5 酸ケ湯 | 6手 | 2 / 48 |

第2〜5面の最短手順には道路への落下が含まれる（第5面は2回）。通行人がいない時をねらう必要がある。

さらに、ブラウザ上で同じ手順を実際のゲームに入力し、5面すべてが「完了」になることを確認した（H=700・909・920 の3通り）。その間 30ms ごとに、kg 表示どうし・引き出し線・人物・雪尺・上の帯の重なり、帯の文字のはみ出し、気象庁の帯の文字のはみ出しを機械検証し、0件だった。

## 実装の約束（GAME HACK 共通）

- 乱数で勝敗を決めない。出現パターンは実データか固定シーケンス（＝覚えられる・RTAが成立）
- 失敗は必ずプレイヤーの操作・判断に帰因できる（理不尽な死なし）
- スマホ縦持ち・親指操作を基本に（タップ領域 44px 以上・safe-area 対応）
- 単一ファイル `index.html`（このディレクトリに置く）。外部依存なし・ビルド不要
- 共有ボタン（𝕏）とポータルへの導線を入れる
- データの出典をゲーム内に明記する
