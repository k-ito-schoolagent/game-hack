# 屋根雪おろし（仕様書）

> ステータス: **公開中（No.08）**。改良の提案は issue へ。はじめての PR 歓迎。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 雪国の冬の重労働と「落とす向き」の判断 |
| 物理化（概念→物理オブジェクト） | 屋根の雪＝斜面上のかたまり（片面3〜4個）。凍着しているかたまりは動かず、押されたかたまりはトタンの上を加速して滑る。ぶつかった雪は一緒に動く（完全非弾性衝突）。日が当たってゆるんだ面では、下の支えを失った雪が自分から滑り出す（連鎖） |
| 権限（現実ではありえない） | 屋根の雪のかたまりの重さ（kg）が見える |
| 技術（習熟でクリア可能にするもの） | 重さと置き場の残り（kg）を見て、どのかたまりを・どの向きに・どの強さで・どの順番で押すかを決める。軽い棟ぎわの雪だけが、強く押せばカーポートを越えて流雪溝まで飛ぶ |
| 失敗の見せ場 | 隣家に落とす／隣との間を埋める「ご近所トラブル」、カーポート直撃・庭の雪山があふれる「カーポート崩落」、道路の通学の子ども・隣のおばあちゃんの目の前に落とす「通学路に落雪」、上の雪や押し戻された雪に「巻き込まれ」。判子は「崩落」、クリアは丸印「完了」 |
| データ（実データ＝固定パターン） | 気象庁の最深積雪（地点別の観測値）を各面の積雪深に使用 |
| 操作（スマホ親指・1操作） | かたまりを、落としたい向き（軒へ／棟へ）にはらう。はらう長さで強さが3段階（弱・中・強） |

概略値（実測ではないもの）: 雪の重さ（積雪1cm・1m²あたり3kg＝密度300kg/m³。かたまりは奥行き1m分）、屋根の勾配・家の寸法・隣家やカーポートまでの距離、トタンの摩擦、押す力、置き場の容量。屋根の雪の深さは「その日の地上の積雪深と同じ」とみなしている。

## 見た目（このゲームの世界の書式）

- HUD: 町内の琺瑯掲示（生成り地・紺の文字・二重罫）。中央に置き場の残り（kg）
- シート: 町内会の回覧板（緑の板・金属クリップ・罫線入りの回覧用紙・明朝の見出し・「雪国町内会 除雪当番」）。失敗は角印「崩落」、クリアは丸印「完了」
- 共通UIの JS/HTML 構造はそのまま。CSS 変数の再定義と、共通ブロックの後ろの追加 CSS で上書きしている

## 物理（決定的・乱数なし）

- 屋根に沿った1次元の運動（刻み 1/240 秒）。動いている雪の加速度は斜面方向に 0.4 m/s²（動摩擦を勾配よりわずかに小さく設定）
- 押す力 J（弱・中・強）を重さ m で割った初速 v0 = J / m。重い雪ほど動かない
- 棟へ押し上げた雪が棟を越えられないと滑り戻り、押した人を巻き込む。反対側の棟ぎわに雪が残っていると越えられない
- 軒から飛び出した雪は放物線で落ちる。カーポートは屋根の高さ 2.4m で当たり判定
- 通学路の通行人は16秒周期の固定ダイヤ（子ども2人・隣のおばあちゃん）。道路に落とすときは人のいない時をねらえばよい

## 実装の約束（GAME HACK 共通）

- 乱数で勝敗を決めない。出現パターンは実データか固定シーケンス（＝覚えられる・RTAが成立）
- 失敗は必ずプレイヤーの操作・判断に帰因できる（理不尽な死なし）
- スマホ縦持ち・親指操作を基本に（タップ領域 44px 以上・safe-area 対応）
- 単一ファイル `index.html`（このディレクトリに置く）。外部依存なし・ビルド不要
- 共有ボタン（𝕏）とポータルへの導線を入れる
- データの出典をゲーム内に明記する
