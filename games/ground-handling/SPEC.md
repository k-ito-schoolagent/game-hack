# グランドハンドリング（仕様書）

> ステータス: **公開中**（No.10）。改善の提案は issue へ。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 空港の地上係員。着陸した到着便を誘導路からスポットへ捌く |
| 物理化（概念→物理オブジェクト） | 機体＝慣性のある車両（大型ほど加速も減速も鈍く、角では減速）。誘導路＝グラフ（曲がれる角は100°まで）。スポット＝大きさの枠（大型スポットにしか大型機は入らない） |
| 権限（現実ではありえない） | 管制塔から指でなぞった線どおりに、機体が誘導路を走る |
| 技術（習熟でクリア可能にするもの） | 固定ダイヤの先読み（次に来る大型機のために大型スポットを空けておく）。出発機の流れ（エプロン誘導路を西向き）に逆らわない経路取り |
| 失敗の見せ場 | 誘導路で2機が鉢合わせ（機首の間 数m）→ 管制の英語交信テロップ → 判子「停止」。スポットが埋まり出口がふさがる → 上空待機4機目 → 判子「待機超過」 |
| クリア | 全便ブロックイン → 丸印「定時」 |
| データ | 大阪国際空港 B滑走路 32L 側を簡略化。到着ダイヤは伊丹の便構成を模した架空の固定ダイヤ（便名・時刻は架空） |
| 操作（スマホ親指・1操作） | 出口で止まった機体から、空いたスポットまで指でなぞる（ドラッグ） |

## 面（時間帯）

| 面 | 到着 | 駐機中で始まる機 | 折り返し |
|---|---|---|---|
| 07時台 一番機 | 4便 | 0 | 40秒 |
| 08時台 朝ラッシュ | 6便（ATR42-600 但馬便を含む） | 1 | 34秒 |
| 12時台 昼の便 | 7便 | 3 | 30秒 |
| 17時台 夕方ラッシュ | 9便 | 3 | 28秒 |
| 20時台 最終便 | 10便 | 3 | 26秒 |

## ルール（実装）

- 着陸機は機種ごとに決まった順で空いている高速脱出誘導路（W3→W2→W1、大型機は W2→W1）に入り、出口で止まって誘導を待つ。出口がすべてふさがると後続は上空待機。待機が4機目になったら失敗
- なぞった線は誘導路の交点にスナップされ、曲がれない角（100°超）は使わない経路で補完される。大きさの合わないスポット・使用中のスポットは管制が拒否（失敗にはならない）
- 動いている機体は、前方の機体と合流・交差で自動的に譲り合う（先に着くほう・止まりきれないほうが優先）。逆向きに向かい合った2機は止まるしかなく、その時点で「鉢合わせ」
- 出発機はトーイングカーで押し出されたあと、エプロン誘導路を西へ進み A1 から誘導路A を抜ける（固定）
- シミュレーションは 1/60 秒の固定ステップ。乱数なし

## ノーミスクリアの根拠

ゲームと同じシミュレーションコードを Playwright 上で固定ステップ実行し、自動方針（大きさの合う空きスポットを選び、東側の連絡誘導路から入ってエプロンを西向きに走る。東向きに走るときは対向がいないときだけ出す）で全5面をクリアできることを確認（反応遅れ 0 / 1.5 / 3 秒のいずれでもクリア。最終面の上空待機は最大3機）。
