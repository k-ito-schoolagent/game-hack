# 年賀状仕分け（仕様書）

> ステータス: **遊べます**（[games/nengajo-sort/](./)）。改善の提案は issue へ。

年末の郵便局の区分作業場。実在の郵便番号つきの年賀はがきを読み、宛先の向きへ弾いて区分棚へ。喪中はがきは通常便へ。誤配が3回で、電話が鳴りやまない。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 年末の郵便局。積み上がる年賀はがきの区分 |
| 物理化（概念→物理オブジェクト） | はがき＝弾くと飛んでいく紙。区分棚＝日本地図の方角に並んだ棚。弾いた向きの棚へ入る |
| ありえない権限（一つだけ） | はがきを指で弾けば、日本中どこの区分棚にも一投で届く |
| 技術（習熟でクリア可能にするもの） | 日ごとの台本（宛先の並び）は固定。都道府県の位置の記憶と、方角へ正確に弾く精度 |
| 失敗の見せ場 | 電話が鳴りやまず、苦情の付箋が貼られる → 業務日報に消印「誤配」 |
| データ（実データ＝固定パターン） | 郵便番号・住所は各都道府県庁のもの（uub.jp で確認）。宛名・差出人は架空 |
| 操作（一つだけ・親指） | 宛先の県がある向きへ弾く |

## 面の構成

12月21日〜25日の5日。日ごとに1通あたりの制限時間が短くなる
