# 花火打上げ職人（仕様書）

> ステータス: **遊べる（playable）**。改良の提案は issue へ。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 花火大会の打上げ。風に流されて、思った場所で開かない |
| 物理化（概念→物理オブジェクト） | 風＝玉を横に流す力（上空ほど強い）。突風＝空を横切って風下へ動く「帯」。煙＝開花点に残り、風で流れ、湿度が高いほど長く残る雲 |
| 権限（現実ではありえない） | 風が見える（夜空を流れる風の筋と、突風の帯） |
| 技術（習熟でクリア可能にするもの） | 帯が筒の上に来る前か後かを読んで打つ「間」。煙が印から抜けるのを待つ「間」 |
| 失敗の見せ場 | 観覧席の上で開き、燃えかすが降ってどよめき →「打上げを中止しております」→ 判子「中止」。煙の中で開いて見えない → 判子「煙幕」。印から3発ずれる → 親方「……代われ」→ 判子「交代」。終了時刻を過ぎる → 判子「時間切」 |
| クリア | 大玉の連発と「玉屋ー！」「鍵屋ー！」→ 丸印「鍵屋」（最終会場は「玉屋」） |
| データ（実データ＝固定パターン） | 気象庁「過去の気象データ」の10分値（平均風速・風向・最大瞬間風速）。開催日・開催時刻の値を使う |
| 操作（スマホ親指・1操作） | タップで打上げ（1回で1発）。PC は Space / Enter |

## 概略値（実データではない部分）

- 画面の左右の方位（会場の見え方を簡略化）: 長岡・大曲は画面右＝東、諏訪湖は画面右＝東北東、隅田川は画面右＝南（スカイツリーのある東を向いて見る）
- 突風の帯の周期・幅（面ごとの固定シーケンス）。強さは 10分値の「平均風速×0.7」〜「最大瞬間風速」の間
- 上空の増速（開花高で最大1.4倍）、会場ごとの画面の縮尺（風 1m/s で流れる量）
- 番組（演目）は本作の固定番組で、2025年の実際のプログラムではない

## 実装メモ

- 単一ファイル `index.html`。物理は `// SIM-BEGIN`〜`// SIM-END` の範囲（固定刻み 1/120 秒）。検証スクリプトはこの範囲をそのまま読み込んで、全会場をノーミスで打ち切れることを確認している
- 各番組の「印」は、その番組の `at` 秒の前後2秒で実際に打った場合の開花位置（突風に乗せる g／合間 l／中間 m）から決めるので、必ず印で開く打ち時がある
- 乱数は花火の星の散り方・風の筋の描画だけ。勝敗には使わない
