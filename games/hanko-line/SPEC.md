# ハンコ決裁ライン（仕様書）

> ステータス: **遊べます**（[games/hanko-line/](./)）。改善の提案は issue へ。

物品購入伺・支出伺・出張命令伺。本物そっくりの起案書類が流れてくる。明細に紛れた「黒毛和牛 5kg」、訂正印のない訂正、順番飛ばしの決裁欄を見抜いて差し戻し、正しい書類には校長印をそっと押す。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 学校の事務室に回ってくる伺い書と、決裁欄のハンコ |
| 物理化（概念→物理オブジェクト） | 書類＝ベルトを流れてくる本物そっくりの伺い書。ハンコ＝傾きと勢いのある物体。勢いよく押すとにじむ |
| ありえない権限（一つだけ） | 臨時採用2日目なのに、校長印を一人で預かっている |
| 技術（習熟でクリア可能にするもの） | 曜日ごとの書類の並びは固定。件名と品物の不一致、公費で買えない物、訂正印、決裁欄の順番などを読む目と、そっと押す手 |
| 失敗の見せ場 | 監査が入り、付箋が書類を埋める → 監査結果通知書に判子「監査」 |
| データ（実データ＝固定パターン） | 予算科目の節名は地方自治法施行規則の節区分による。様式番号・校名・人名・単価は架空 |
| 操作（一つだけ・親指） | ハンコを決裁欄へ、不備の書類は差戻箱へドラッグ |

## 面の構成

月曜〜金曜の5日。書類49枚はすべて別の題材で、日ごとに流れが速くなる
