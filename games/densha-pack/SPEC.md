# 満員電車パッキング（仕様書）

> ステータス: **遊べます**（[games/densha-pack/](./)）。改善の提案は issue へ。

朝の中央線快速、国分寺から中野まで8駅。ホームに並ぶ会社員・学生・リュックの人・ベビーカーの親子を、奥へ詰めて乗せていく。ドアラインを越えたら「ドアが閉まりません」。

## 発想の型

| 要素 | 内容 |
|---|---|
| 題材（みんなが知っている現実） | 朝の満員電車。「奥へお詰めください」でも乗り切れない、あの数十秒 |
| 物理化（概念→物理オブジェクト） | 乗客＝体型・年齢・持ち物ごとに幅と奥行きが違う体。ドアから入り、奥へ進んで他の乗客か壁にぶつかったところで止まる。積み上がりがドアラインを越えるとドアが閉まらない |
| ありえない権限（一つだけ） | 乗客を指でつまんで、車内の好きな位置へ押し込める |
| 技術（習熟でクリア可能にするもの） | 駅ごとの乗客の並びは固定。誰をどこに入れるかの順序と位置取りを覚える技術 |
| 失敗の見せ場 | ドアが閉まりかけては開き、車内放送「ドアが閉まりません」→ 遅延証明書に判子「閉扉不能」 |
| データ（実データ＝固定パターン） | 国土交通省「東京圏における主要区間の混雑率」令和7年度（中央線快速 中野→新宿 158%）。番線は各駅の公開情報による概略、発車時刻は架空 |
| 操作（一つだけ・親指） | 指を置いて左右にずらし、離すと乗り込む |

## 面の構成

中央線快速 上り 国分寺→三鷹→吉祥寺→西荻窪→荻窪→阿佐ケ谷→高円寺→中野（8駅）
